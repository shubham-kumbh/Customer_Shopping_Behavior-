

# Customer Shopping Behavior Analysis

## Project Overview

This project demonstrates a complete end-to-end Data Analytics workflow, covering data cleaning, exploratory data analysis, database management, business intelligence, and dashboard development. The objective was to transform raw customer shopping data into meaningful business insights and support data-driven decision-making.

## Project Workflow

### 1. Data Collection & Preparation (Python)

* Imported the customer shopping dataset into Jupyter Notebook.
* Explored the dataset to understand its structure and quality.
* Performed data cleaning and preprocessing.
* Handled missing values, duplicate records, and data inconsistencies.
* Prepared the dataset for further analysis.

### 2. Database Creation & Data Storage (MySQL)

* Created a MySQL database to store the cleaned dataset.
* Loaded the processed data from Python into MySQL.
* Established database connections and managed customer transaction data.

### 3. Business Analysis (SQL)

* Wrote SQL queries to answer key business questions.
* Analyzed customer purchasing behavior and spending patterns.
* Identified high-value customer segments.
* Performed aggregations, filtering, grouping, and trend analysis using SQL.

### 4. Data Visualization & Dashboard Development (Power BI)

* Connected MySQL database to Power BI.
* Developed an interactive dashboard to visualize customer behavior.
* Created KPI cards, charts, filters, and slicers for dynamic reporting.
* Enabled users to analyze customer trends and revenue patterns through interactive visualizations.

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* MySQL
* Power BI
* Jupyter Notebook

## Key Outcomes

* Cleaned and transformed raw customer data for analysis.
* Built a structured MySQL database for efficient data management.
* Generated business insights using SQL queries.
* Developed an interactive Power BI dashboard for decision-making.
* Demonstrated an end-to-end analytics workflow from raw data to business intelligence.

## Business Value

The project helps businesses understand customer purchasing behavior, identify revenue-driving customer segments, and make informed decisions based on data-driven insights.
